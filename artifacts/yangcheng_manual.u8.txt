三、 决赛内容
本次决赛分为 AI 融合靶场安全评估挑战赛和 AI Agent 解题挑战赛。
1、AI 融合靶场安全评估挑战赛
（1）竞赛模式
比赛中选手们需要对融合靶场开展安全评估，发现靶场环境中存在的各类安

安全事件影响范围，定位事件关键线索，完成对整体安全事件画像，有可能还需

攻防能力，选手将面对一系列仿真 AI 环境，涵盖从信息搜集到模型防御的各个
环节。选手需要从攻击者视角识别并利用 AI 模型中的安全漏洞，实施诸如对抗
样本攻击、模型反向工程、数据投毒攻击等技术，挑战模型的安全性与稳健性。
同时，选手需运用防御技能，如增强训练和模型加密，来保护 AI 系统免受潜在
威胁。
（2）计分规则
比赛分为渗透测试、应急响应两个模块，共用同一靶场环境。每道题目根据
题目难度设置不同分数（较低难度 100 分、中等难度 200 分，较高难度 300 分），
参赛选手根据题目描述和要求，提交指定格式的字符串（如 flag、命令行、文件
名、时间戳、IP 信息等），回答正确则会获得相应分数。同时，每道题目前三
名成功解题的团队将额外获得本题分值的 15%、10%和 5%的奖励分。
2、AI Agent 解题挑战赛
（1）竞赛模式
比赛期间，平台将分批开放大量 CTF 题目，题量设计明显超过人工手工完
成能力，旨在引导参赛队伍依靠自研 Agent 进行批量分析、自动尝试、环境交互
和持续提交，体现 AI 在复杂任务处理中的效率优势。比赛仅开放统一 API 接口。
参赛队伍需通过 API 获取题目信息、访问题目环境、提交 Flag 和获取反馈结果。
平台不提供传统网页端手工做题入口。比赛过程中，参赛队伍可以持续与自行构
建的 Agent 进行交互，包括设定任务目标、调整解题优先级、查看运行状态、优
化提示词、分析执行结果和修正策略方向。赛事允许选手在合理范围内参与 Agent

（2）计分规则
赛题以 CTF 入门至进阶方向为主，可覆盖 Web、Misc、Crypto、脚本分析、
漏洞利用基础等类型，重点考察 Agent 对题目描述、附件、环境反馈和错误信息
的综合处理能力，以及选手对 Agent 解题过程的组织、监督和优化能力。比赛采
用 Flag 计分方式。参赛队伍通过 API 成功提交有效 Flag 后获得对应分数。计分
规则采用递减模式，每道题将根据难度设置不同的初始分值，题目分数将会随着
解题人数的增加而逐步减少，下降幅度为题目初始分数的 1%，题目最低分数为
初始分数的 80%，如题目 A 初始分数为 200，则第一人答出获得 200 分，第二名
198 分，以此类推，20 名及以后该题目分数为 160 分。

取消队伍成绩；
 禁止对录屏进行剪辑或加工。录屏内容必须具备完整的解题过程：解题
关键步骤不可省略，获取 Flag 得分过程必须完整清晰。若录屏内容缺少关键步
骤、解题情况和所录视频实际情况不符时，将被视为违规，并取消队伍成绩；
 录屏格式需为 mp4 格式，命名格式为：队伍名-选手姓名-手机号.mp4。
