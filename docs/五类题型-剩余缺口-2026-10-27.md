## 二、还缺的（按"值不值得装"排序）

### Pc · 值得装，但只在必要时（中等体积）

| 缺口 | 候选 | 体积 | 说明 |
|---|---|---|---|
| **libc 偏移数据库** | `libc-database`（niklasb/libc-database）+ `one_gadget` | ~数 MB + gem | Pwn 的 `ret2libc` 没有它就得靠猜 libc 版本。`one_gadget` 是 Ruby gem（镜像里 `one_gadget` 已有？需查）。**建议装 libc-database（可选联网 `get` 才下 libc）** |
| **Python 反编译** | `uncompyle6` / `decompyle3` / `pycdc` | ~5 MB | `.pyc` 题目前只能 `dis` 字节码手看。`pycdc`（C++，需编译）对 3.8+ 最好；`decompyle3` 只到 3.8。**建议装 `pycdc`** |
| **APK 二次校验** | `apksigner` `aapt` | ~10 MB | 校验签名/读 `badging`；`apktool` 已能解，但签名校验缺 |
| **隐写（音频/文档）** | `steghide` 已有；`deepsound`? `mp3stego`? | 小 | 音频隐写目前只能靠 `ffmpeg`+手工；`mp3stego` 是冷门但常考 |
| **Misc 压缩包爆破** | `john`（已有）+ `zip2john/rar2john/7z2john` | 已有 | 确认 john 的 `*2john` 脚本都在即可 |
| **流量分析辅助** | `networkminer`? `brim`? | 大（GUI/Electron） | 不建议，`tshark`+`scapy` 够用 |

### Pb · 想要但代价大（只在真有需求时）

| 缺口 | 候选 | 体积/代价 | 为什么现在不装 |
|---|---|---|---|
| **Android 动态/原生** | `frida`（113 MB）、`objection` | +150 MB | 静态 `jadx` 已覆盖大多数 APK 题；动态要 root 设备/模拟器，沙箱里跑不动 |
| **APK 反编译（更强）** | `jadx` 已装；`Ghidra` 的 Android 支持 | 见下 | 需要 Ghidra |
| **原生反编译（伪代码）** | `Ghidra` 12.1（~400 MB + JDK）或 `IDA`（商业） | +500 MB～ | **最大的缺口**：`.exe/.so/.elf` 要看伪代码目前只能 `r2`（反汇编）+ 手工。装了 Ghidra 才算真补齐 Reverse 的"反编译"能力 |
| **模糊测试** | `AFL++`（~100 MB） | +100 MB | CTF 里 fuzz 出漏洞的题很少；`angr`（已有）覆盖符号执行类 |
| **密码学重型** | `sagemath`（~1.5 GB）、`z3`（已有 `sympy`/`z3`） | +1.5 GB | 只有少数"格密码/数论"题需要；磁盘只剩 ~7 GB，装了要挤掉别的 |
| **UE5 Oodle 解压** | 需 Unreal SDK 的 `OodleLZ_Decompress`（私有） | 不可分发 | 千千的咲那类题的关键卡点；开源侧只有 `oo2core` 重实现（法律风险），**建议不碰** |

### Pd · 不建议

| 候选 | 原因 |
|---|---|
| `semgrep` | Kali 源 404 + 容器无网拉规则（已从提示词里明确排除） |
| `ropper` | 依赖 `filebytes` 用了 Py3.12 已移除的 `ast.Str`，装到 3.14 上必崩 |
| `zsteg` | gem 依赖离线取不到（`stegoveritas` 已顶替） |
| `pwndbg` | 比 `gef` 重、依赖 gdb python 环境易冲突；`gef` 已够 |
| `REA`（morluto/rea） | 229 个 MCP 工具 / 4.2 MB，内核 `MAX_DESCRIBE_CHARS=24000` 只能看见 4 个；且**没有 Ghidra/Hopper 时 `rea inspect` 直接 `provider_unavailable`** |

## 三、一句话结论

- **Web / Crypto / Misc 常用题**：现在基本够用（这一轮补的正是这三块的硬缺口）。
- **Pwn**：缺 `libc-database`（小、值得装）；`gef` 已补。
- **Reverse**：**最大的洞是"反编译"**——`r2` 只能反汇编。要真正补齐得装 Ghidra（+400 MB + JDK），这是唯一"装了会明显变强但很重"的一项，需要你决定。
- **Android**：`jadx/apktool/dex2jar` 已补（静态够用），动态（frida）不建议。

## 四、下一步建议（按性价比）

1. `libc-database` + `pycdc`（+几 MB，补 Pwn 与 pyc 题）—— 建议做
2. `aapt` / `apksigner`（+10 MB，APK 签名/清单校验）—— 建议做
3. `Ghidra`（+500 MB）—— **需要你拍板**，磁盘要腾 ~1 GB
4. 其余（frida / sagemath / AFL++）—— 默认不做
