## 三、集成建议：按「性价比」分三档

### A 档 · 立刻能装、体积小、离线可用（建议直接进镜像）
| 项目 | 装法 | 增量 |
|---|---|---|
| `repak` | 直接取 Release 的 `repak` 静态二进制（Rust 单文件） | ~2 MB |
| `ropper` | `pip install ropper` | ~1 MB |
| `jwt_tool` | `pip install -r requirements.txt` + 软链 `jwt_tool.py` | <1 MB |
| `Fenjing` | `pip install fenjing` | ~10 MB |
| `SSTImap` | `pip install -r requirements.txt` | <1 MB |
| `bkcrack` | cmake 编译或取 Release 二进制 | ~1 MB |
| `stegoveritas` | `pip install stegoveritas` | ~5 MB |
| `volatility3` | `pip install volatility3` | ~11 MB |
| `zsteg` | `gem install zsteg`（需 ruby） | ~19 MB |
| `pcapfix` | 源码编译 | <1 MB |
| `nuclei-templates` | 拷到 `/opt/nuclei-templates`，`nuclei -t` 指过去 | 61 MB |
| `libc-database` | 拷脚本；**注意**它要联网拉 libc，离线只能查已缓存库 | 小 |

**A 档合计约 +110 MB**，能把 Web 的 JWT/SSTI、Pwn 的 ropper、Crypto 的空缺、Misc 的隐写/取证的短板基本补齐。

### B 档 · 要装运行时/构建，但价值高（建议装）
| 项目 | 前提 | 增量 |
|---|---|---|
| `jadx` | 需 JDK 17+；用 Release zip 免构建 | ~40 MB(含 JRE) |
| `Apktool` | 需 JDK；用 Release jar + wrapper | ~15 MB |
| `dex2jar` | 需 JDK；用 Release | ~10 MB |
| `RsaCtfTool` | `pip install -r requirements.txt`（部分攻击要 Sage） | ~50 MB |
| `pwndbg` **或** `gef` | gdb 已有；pin 一个版本 | ~10–60 MB |
| `AFLplusplus` | 需 clang/llvm，`make source-only` | ~100 MB |
| `crypto-attacks` | 需 Sage 才有完整能力 | 小(JRE/Sage 另算) |

**关键依赖：SageMath**（约 1 GB，Kali 有 `sagemath` 包）。crypto-attacks 很多攻击、以及「求离散对数/多项式/格」都靠它。要不要装 Sage 是单独决策。

### C 档 · 体积大 / 特殊运行时，建议先评估再决定
| 项目 | 体积 | 代价 |
|---|---|---|
| `ghidra` | 397 MB 源码；**用 Release 约 400 MB + JDK 17** | 磁盘与构建都重；但对无 IDA 的平台是质的提升 |
| `CUE4Parse` + `FModel` | 66+7 MB，需 **.NET 8 SDK/运行时** | 才能解 UE5 Oodle 那类题（千千的咲）；先加 `repak` 试探，不行再上这套 |
| `frida` | 需 submodules + 目标机注入 | 动态分析，容器内价值有限 |
| `wpscan` | 88 MB + Ruby | 只在打 WordPress 时用得上 |
| `testdisk` | 5.7 MB | apt 一行即可，其实该进 A 档 |

## 四、我的建议顺序（等你确认）

1. **先做 A 档**（~110 MB）：改动小、风险低、覆盖面广，尤其是 `repak` + `nuclei-templates` + `ropper` + `RsaCtfTool` 这几样性价比最高。
2. **再做 B 档的 Android 三件套**（jadx/Apktool/dex2jar，都只要 JDK）：这是目前**最明显的硬缺口**——任何 APK 题现在都打不开。
3. **UE 题**：先用 `repak` 验证「flag 是否在未压缩资源里」；确认要 Oodle 再上 `CUE4Parse`+.NET。
4. **Ghidra / SageMath**：单独决策，因为它们各自就占几百 MB～1 GB。Kali 可用磁盘现在只有 **12 GB**，要装它们得先清 Docker 构建缓存（还有 ~6.8 GB 可回收）。
