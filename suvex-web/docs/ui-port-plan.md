## 阶段划分

### 阶段 1（本次）：语言 + 总览优先级 ✅

验收：`npx vitest run src/i18n src/components/overview` 与 `tsc -b` 通过；
总览右栏出现 P0–P4，点「查看」落到对应过滤的发现列表。

### 阶段 2：任务页两栏（截图 #1）

- `/scans` 改为 `列表 | 详情` 两栏：左栏状态筛选 + 任务卡（标题、目标、进度、结论数）；
- 右栏空态文案（"从左侧选择一个任务查看执行细节"），选中后显示现有的事件流 / 详情；
- 移动端退化为单栏（列表 → 点入详情）。

验收：现有 `ScansPage` 的交互测试全部保留通过；新增两栏切换用例。

### 阶段 3：资产测绘画布（截图 #2）

- 资产按「目标 → 端口/服务 → 发现」分层，力导向或树布局；
- 复用 `data/asset-host.ts` 的既有分组，不新增后端接口；
- 大图谱要分页/聚簇（>300 节点先按目标聚合）。

验收：空库/单目标/多目标三态截图；拖拽与缩放有最小用例。

### 阶段 4：系统设置二级导航（截图 #3–#6）

- 左列二级导航：常规 / 网络代理 / 版本更新 / 授权告知 / 网络限制 / 性能配置 / 数据维护 / 开发者与 MCP；
- **数据维护**：导出数据库、清空业务记录、恢复初始配置（对应后端能力缺失的项只读展示原因）；
- **网络限制**：允许网段列表（复用 `SUPEX_CHAT_SHELL_ALLOWED_HOSTS`）、已确认域名、隔离状态；
- 每个操作必须有二次确认 + 结果回执。

验收：每个子页有独立路由（`/settings?tab=data` 或子路由），刷新后停在原 tab。

### 阶段 5：剩余语言覆盖

- 把老页面的中文字面量逐步迁进 `t()`：先导航、空态、按钮，再表格列名；
- 每迁一页，在 `i18n` 字典里补齐 7 语言；缺译时回落中文并在开发态 `console.warn`。

## 约束

- **不新增依赖**：i18n、图表都用现有能力（Context + div/SVG）。
- **不改后端契约**：所有数据来自现有端点；缺数据的模块先只读或空态。
- **一次一刀**：每个阶段独立提交、独立测试、独立部署；不合并成一次大改。
